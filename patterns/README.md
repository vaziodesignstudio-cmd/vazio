# Patterns

Padrões **estruturais** que se repetem em sites de empresa de limpeza entregues pela Vazio. Independente da ID visual de cada cliente.

Regra para entrar aqui: o padrão precisa ter sido usado em pelo menos 2 projetos. Antes disso, é uma ideia, não um padrão.
